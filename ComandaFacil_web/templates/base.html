WhatsApp ao lado do sistema

O WhatsApp Web não permite ser embutido dentro de outra página. Este modo abre o WhatsApp em uma janela encaixada ao lado direito da tela, para você atender e lançar o pedido sem trocar de aba.

• O navegador só consegue ajustar janelas que ele mesmo abriu; por isso use “janela própria” uma vez para o sistema ocupar a metade esquerda.
• Permita pop-ups para este endereço se o navegador perguntar.
• Para mudar a largura depois, feche a janela do WhatsApp e acople de novo.
• Atalho do Windows: Win + ← no sistema e Win + → no WhatsApp.
